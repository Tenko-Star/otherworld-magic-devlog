# 小说阅读器

使用 Next.js 的本地前后端项目。界面参照提供的 ChatGPT 网页截图，左下角使用指定头像。页面中的模型名称和语音图标仅用于还原外观，不连接 AI、账号或语音服务。

在本目录启动：

```powershell
cd C:\Users\admin\Documents\magic\viewer
npm install
npm run dev
```

打开 http://127.0.0.1:3000 。默认仅监听本机。

- 左侧历史仅作展示，每次刷新页面从 100 个标题中随机抽取 24 个；不关联小说章节。
- 右侧 Outputs 或底部加号可选择章节。右侧目录可独立滚动，当前章高亮并自动居中，首尾留出滚动空间。
- 侧栏顶部搜索按钮可以按标题或序号查找章节。
- 输入普通消息后显示约 20 秒的模拟思考状态，再追加长度随机的本地文本，不调用 AI。
- 输入 `/next` 或 `/prev`（不区分大小写），同样等待约 20 秒，再追加下一章或上一章正文；网络读取耗时较长时可能稍晚完成。首尾不循环。
- 输入框不再按章节标题或序号导航，查找章节请用搜索入口。空输入不发送，思考中不重复提交。
- 点击目录或上下章按钮仍立即切换并清空当前对话；切换章节、新建对话或离开页面会取消尚未完成的回复。
- 点击 Outputs 标题旁的“＋”会重新请求后端扫描小说目录并更新列表，不重载页面，也不更换左侧随机标题。刷新失败保留原目录；当前章被移除时保留已显示正文，但停止前后章导航，需手动选择现有章节。
- 正文末尾提供上一章、下一章按钮；输入框上方的向下箭头可直接跳到对话末尾。
- Share 复制当前本地阅读链接；正文下方复制按钮复制当前章节原文。
- 右上角按钮切换 Outputs；窄窗口默认收起该面板。

正文直接读取 `viewer` 上一级目录中的 `第X章_标题.md` 文件，支持中文和阿拉伯数字章节序号。不会修改、复制或移动小说正文，也不会读取 `db/` 和 `temp/`。新章节保存为相同命名格式后，点击 Outputs 旁的“＋”刷新即可。

后端接口：

- `GET /api/chapters`：按章节序号排列的目录。
- `GET /api/chapters/[id]`：章节标题与原始正文，`id` 是经过 URL 编码的完整文件名。

当前正文以标题和普通段落为主，阅读区支持这些格式以及分隔线；不执行 Markdown 中的 HTML。运行时需要保留上一级目录中的小说文件，因此不能只将 `viewer/` 单独部署为静态网站。

如需以生产模式运行，在本目录依次执行 `npm run build` 和 `npm start`。
