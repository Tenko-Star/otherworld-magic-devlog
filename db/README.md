# 《异世界魔法开发日志》创作资料入口

本入口只保存公共的读取、分类与维护说明，不存放具体剧情、章节摘要或当前进度。写作约束统一见 [AGENTS.md](../AGENTS.md)。

## 资料分类

| 文件 | 用途 |
| --- | --- |
| [settings.md](settings.md) | 公共世界设定、教育分级与院系、资源与币制、带宽和培养机制、技术路线、篇幅要求与待定问题 |
| [persons.md](persons.md) | 主要人物与指定配角档案、关系、出场事实、确定的后续安排与待审方案 |
| [scenes.md](scenes.md) | 地域、店铺、住处、家庭生计与可用场景，区分已有依据和新增设定 |
| [outline_overview.md](outline_overview.md) | 跨章节总纲、尚未确定章号的卷级规划、备选场景与长期伏笔 |
| `outline_<start>_<end>.md` | 对应十章区间的剧情规划，已有文件：[outline_1_10.md](outline_1_10.md) |
| `summary_<start>_<end>.md` | 对应十章区间的已生成正文摘要、实际事件与衔接记录，已有文件：[summary_1_10.md](summary_1_10.md) |
| [progress.md](progress.md) | 当前进度、待讨论检查点与资料变更记录 |
| [../temp/](../temp/README.md) | 临时交接文档 |

正文仍在仓库根目录，按原章节文件名独立保存；`summary` 文件不合并或替代正文。

## 分段与命名

- 摘要与章节大纲使用相同的固定十章区间：`1_10`、`11_20`、`21_30`，依此类推。章号使用不补零的十进制数字。
- 区间尚未写满时保留完整区间名，例如只完成前五章仍使用 `summary_1_10.md`。注明实际收录范围，不虚构剩余章节。
- 第十一章起使用 `summary_11_20.md` 与 `outline_11_20.md`；有实际记录或规划时再创建文件，并更新本入口的链接。
- `outline` 保存计划，`summary` 保存已写事实。二者不能互相替代，也不能把计划中的事件登记为已经发生。
- 未确定章号的卷级规划暂留总纲。确认章号后，将具体章节规划迁入对应分段，不为了填满文件而擅自分配剧情。

## 读取与维护

1. 写作前同时读取 `AGENTS.md`、公共设定、人物资料、相关场景设定、进度，以及目标区间的章节大纲、相关摘要和前章正文；涉及跨区间衔接时同时读取前一区间，涉及全书走向时读取总纲。
2. 用户最新明确要求优先于旧资料；区分确定设定、待审方案和已写事实。聊天摘要与临时交接不能替代正式资料。
3. 写作或修订后，将实际事件、时间线、人物关系、能力和认知边界、伏笔与衔接更新到相应 `summary`，人物档案同步至 `persons.md`，地点布局与生计同步至 `scenes.md`；规划变化更新到相应 `outline`，共用设定与进度分别更新到对应文件。
4. 保留原有事实和待定状态；遇到资料缺失或冲突时明确记录，不擅自补造、改写核心机制或把候选方案定案。
5. 本目录与 `temp/` 均纳入 Git 管理。临时交接中的已确认信息应同步回正式资料，避免只有临时文件保存有效结论。
