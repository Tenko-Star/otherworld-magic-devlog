# 异世界魔法开发日志

一部以中世纪欧洲风格的魔法世界为背景，围绕程序员的异世成长、魔法研究与工坊经营展开的长篇小说。

**当前进度：第一至第十二章初稿已完成，待审阅。** 前五章完成一轮润色，第六章调整了母亲一处对白；最新章节为《刻下来的字》，故事处于伊恩七岁那年初夏。

## 作品摘要

加班至深夜的程序员林砚遭遇闯红灯的卡车，再醒来时，成了河湾镇铁匠家的婴儿伊恩。他从学说话、认字开始重新生活，在父母的劳作中发现：魔法并不遥远，它藏在炉边的保温、窗边的针线和集市上的日常事务里。

六岁进入学堂后，伊恩与莉娅、托马斯一起学习感知和引导魔力。从点亮一团微光，到帮家里处理线头，他逐渐把前世观察、记录和拆解问题的习惯带进练习。两种不同咒语中相同的术节，让他开始追问：在最终效果出现之前，魔法究竟已经做了些什么？

目前的故事已写到他在家人与伙伴帮助下，保留微弱的临时准备，连续整理线头，并交替使用微光与理线。他已在近距离换目标时取得有限成功；首次长时维持延续约一上午，却因精神疲劳睡了约一天。随后，他自行在铜料上刻写完整微光咒文，做出隔日重新供能仍能发光的粗糙试片。中间准备的刻画保存、匕首库、可重入与工坊经营仍待后续展开。

| 第四章 | [第一堂魔法课](第四章_第一堂魔法课.md) | 六岁的伊恩进入学堂，结识莉娅与托马斯。在玛莎指导下，三人借助器具练习感知、引导和停止魔力。伊恩第一次让叶片偏动，也明白人体只能短时缓冲魔力，无法长期积蓄。 |
| 第五章 | [一盏不太争气的灯](第五章_一盏不太争气的灯.md) | 三名伙伴学习微光术，在老师、家人与彼此的帮助下辨别失败原因，最终都能照亮木牌供同伴读字。回家展示成果后，伊恩听出母亲整理线头的咒语与微光术存在相似咒段。 |
| 第六章 | [还没有亮的时候](第六章_还没有亮的时候.md) | 伊恩学习咒文书写，确认重复术节，并向母亲学会整理线头。伙伴帮助他区分省略与停顿、调整实验位置；父母的学院往事也逐渐显露。入秋后，他两次完成微光术中途短暂停顿后的续接，开始探索尚未显现效果的中间过程。 |
| 第七章 | [岔口的另一边](第七章_岔口的另一边.md) | 伊恩尝试换接两种魔法的后半段，却因目标位置和引导习惯不同屡次失败。伙伴协助布置与观察，母亲指出操作差异，父亲提出准备后再作选择。他最终能在同一处岔口选择发光或整理线头，却发现准备过程用过便无法保留。 |
| 第八章 | [留下来的那一点](第八章_留下来的那一点.md) | 伊恩发现持续理线并不能保留前面的准备。在家人与伙伴帮助下，他降低维持量，区分准备与实际输出，终于用同一次准备理好两根线。 |
| 第九章 | [第二遍不用](第九章_第二遍不用.md) | 冬季练习后，伊恩能用一次准备交替理线与发光，让家人和老师看见缩短重复咏唱的价值。换到另一个位置时，光却仍偏回旧目标。 |
| 第十章 | [空箱子那边](第十章_空箱子那边.md) | 伙伴借空箱子排查旧位置的牵连。伊恩逐渐学会在保留近处准备时松开原方向，取得近距离换目标的有限成功，并帮助母亲照明缝衣。 |
| 第十一章 | [睡过了午饭](第十一章_睡过了午饭.md) | 伊恩首次将微弱准备维持约一上午，却因持续注意而疲惫，睡了约一天。恢复后，他向母亲借暖布板观察，开始寻找不必一直靠自己照看的办法。 |
| 第十二章 | [刻下来的字](第十二章_刻下来的字.md) | 伊恩观察暖布板，从炭字试验转向自行刻写。在父亲提供的边角铜料上，他终于引出微光，隔日再次成功；接下来，他想留下的却只是咒文中间的准备。 |
